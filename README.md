# Halloween-Drop
Um Jogo de Halloween em que você tem
que pegar os doces para passar de fase.

O Jogo contém 120 fases, de 30 em 30
fases, você encontra um Boss com mecanicas
diferentes, se adapte!

# Como Jogar

Você controla o Jack O' Lantern
com A/D e W/Space ou apertando os
botões/arrastando no Android.

Desvie das travessuras e colete os Doces,
derrote os bosses e salve o Halloween!

### Como Derrotar os Bosses:

**No Computador**: Desvie dos seus ataques com
W, A, D, Space ou ← ↑ →, pegue as espadas e pule
com W, Space ou ↑ para lança-las nos Bosses

**No Celular**: Desvie dos seus ataques com os
botões <, >, JUMP ou arraste o dedo na tela,
pegue as espadas e aperte o botão SW/Sword para
lança-las nos Bosses
